### 문제 설명

<p>각 격자가 흰색 또는 검은색으로 칠해져 있는 $N$행 $M$열의 격자판이 주어진다.</p>

<p>다음과 같은 행동을 "V자 색칠하기" 라 하자:</p>

<ol>
	<li>흰색 격자를 하나 선택한다.</li>
	<li>선택한 격자부터 시작하여 왼쪽 위 대각선을 따라 움직이면서 흰색이 아닌 격자가 나오거나 외부로 빠져나가기 전까지의 격자들을 모두 파란색으로 칠한다.</li>
	<li>선택한 격자의 한 칸 오른쪽 위 격자부터 시작하여 오른쪽 위 대각선을 따라 움직이면서 흰색이 아닌 격자가 나오거나 외부로 빠져나가기 전까지의 격자들을 모두 파란색으로 칠한다.</li>
</ol>

<p>"V자 색칠하기"를 두 번 했을 때 가능한 파란색 격자의 최대 개수를 구하여라.</p>

<p style="text-align: center;"><img alt="" src="" style="width: 278px; height: 127px;"></p>

<p>그 후, 5행 9열의 격자에서 V자 색칠하기를 하면 다음과 같이 총 11개의 격자가 파란색으로 칠해진다.</p>

### 입력 

 <p>첫 번째 줄에 $N$과 $M$이 공백으로 구분되어 주어진다.</p>

<p>두 번째 줄부터 $N$개의 줄에 걸쳐 격자판에 대한 정보가 주어진다. 각 줄에는 $0$ 또는 $1$로 이루어진 길이 $M$인 문자열이 주어진다. $N$개의 줄 중 $i$번째 줄의 $j$번째 문자가 $1$이면 격자판에서 $i$행 $j$열의 격자가 흰색, $0$이면 검은색임을 뜻한다. ($1 \le i \le N, 1 \le j \le M$)</p>

### 출력 

 <p>첫 번째 줄에 가능한 파란색 격자의 최대 개수를 출력한다.</p>
